# WA Legacy

Лёгкий клиент мессенджера для старых iOS (6–9) с входом по QR-коду. При запуске сразу показывается QR: на телефоне открой WhatsApp → Связанные устройства → Привязка устройства и отсканируй код. После этого откроются все чаты и переписка.

Дизайн: на iOS 6 — классический объёмный (градиенты, обводки), на iOS 7–9 — плоский минималистичный.

```
iPhone (iOS 6–9)  ──HTTP/JSON──►  bridge (Node.js + Baileys + ffmpeg)  ──►  WhatsApp
```

Приложение не реализует протокол WhatsApp само (на iOS 6–9 это нереально: нет современного TLS и криптографии), поэтому работает через **мост** (`bridge/`) на твоём ПК или VPS.

## Что умеет

- текстовые сообщения, список чатов, время;
- голосовые: запись (держи кнопку 🎤), отправка, воспроизведение;
- фото: отправка (сжимается до 1280 px), превью в чате, просмотр с зумом;
- видео: съёмка или выбор из галереи, отправка, воспроизведение (мост переводит видео в формат, который тянет старый iPhone: H.264 baseline, 480p);
- превью приходят мгновенно, всё скачанное кэшируется на диске.

## 1. Запусти мост

Нужны Node.js 18+ и **ffmpeg** (с libopus и libx264; в обычных сборках они есть).

```
cd bridge
npm install
BRIDGE_TOKEN=придумай_ключ npm start
```

Порт 3000. Если iPhone в той же Wi-Fi, адрес вида `http://192.168.0.10:3000`. Для доступа из интернета поставь мост на VPS и обязательно задай `BRIDGE_TOKEN`: через мост виден твой WhatsApp.

## 2. Собери IPA

1. Залей проект в репозиторий GitHub (ветка `main`).
2. Actions → **Build IPA** запускается сам при push (или вручную через *Run workflow*).
3. Готовый файл: Releases → **latest** → `WALegacy.ipa`.

Если сборка упала (красный крестик): открой её, скопируй текст ошибки и отправь Claude.

## 3. Установи на iPhone

IPA **не подписан**: джейлбрейк + AppSync Unified (установка через Filza/iFile) либо подпись своим сертификатом.

## 4. Войди

Открой приложение → **Server** → адрес моста и ключ → отсканируй QR.

## Иконка

Стоит своя нейтральная иконка (зелёный чат-пузырь). Логотип WhatsApp — товарный знак, поэтому он не нарисован. Свою иконку положи в `app/Resources/`: `Icon.png` (57×57), `Icon@2x.png` (114×114), `Icon-60@2x.png` (120×120), `Icon-60@3x.png` (180×180).

## Ограничения

- «Кружочки» (круглые видеосообщения) не поддерживаются: используемая библиотека не умеет их отправлять. Обычное видео работает.
- Неофициальные клиенты нарушают условия WhatsApp, аккаунт могут заблокировать. Лучше тестировать на запасном номере.
- Первое открытие длинного видео занимает время: мост сначала конвертирует его, потом оно кэшируется.
- Сообщения хранятся в памяти моста; после перезапуска история начнётся заново (вход сохраняется в `bridge/auth`).
- Документы, стикеры показываются как заглушки; группы без отдельных настроек.
- Публичные сервисы и устаревшие корневые сертификаты на iOS 6–9: для моста используй `http://` или свой прокси.
